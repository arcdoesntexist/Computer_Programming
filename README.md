## 🛠️ Requirements & Tools

* **Language:** C (C99 / C11 standard)
* **Compiler:** `gcc` (MinGW / Clang / MSVC)
* **OS:** Windows

---

## 🚀 How to Run

### Using GCC (Command Line)

1. **Compile a source file:**
```bash
gcc C1-E1.c -o C1-E1.exe

```


2. **Run the executable:**
```bash
./C1-E1.exe

```



---

## 📝 Naming Conventions

* `CX-EY.c` : **C**hapter `X`, **E**xercise `Y` source code.
* `try.c` : Temporary file used for experimenting with concepts before committing to an exercise.
